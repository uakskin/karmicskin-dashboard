Karmic Skin

Design System

This document defines how Karmic Skin looks. Use it whenever you build something for the brand — a web page, an email, a social post, a dashboard, packaging — so every piece is consistent. Colour, type, spacing and components are set out in the sections below.

01 · Principles

Four principles behind every page

Read these first. Every rule in this document follows from them.

01

Everything has a job

Every colour, size and space is here for a reason. If you cannot say what something is for, leave it out.

02

Use as few colours as possible

The fewer colours on a page, the more considered it looks. Most of any Karmic page is Porcelain with Carbon Black text. Add another colour only when it has a clear job.

03

Build hierarchy with size and weight

To make something stand out, make it larger or bolder — not a different colour. All text is one colour.

04

One system, every surface

Use these rules everywhere Karmic appears: the website, emails, dashboards, social posts and packaging. Consistency is what makes it a brand.

Don't

Carbon Black and Dark Green never clash, because they are used for different things — one for text, one for backgrounds. Dark Green stays on backgrounds so it keeps its meaning: a green panel should feel deliberate, not used everywhere.

Backgrounds

Three background colours, and only three

Porcelain
The default. Use it for almost every background.
Sand Dune
A soft tint. Use it for the occasional section, to add rhythm to a long page.
Dark Green
A branded background, for a panel or section that should feel distinctly Karmic.

Every background in Karmic Skin is one of these three. Carbon Black is never used as a background.

Borders

Separate things with space, not boxes

Do not put a box around content to group it. Use space and background colour instead. A border belongs only on something a user interacts with — an input field, a dropdown, an outline button. When you use a border, make it Carbon Black and 1px wide.

Brick Red

Red is for the main action — nothing else

Brick Red is the primary button only — one per screen. The secondary button is filled Carbon Black; the ghost button is a Carbon Black outline.

Use Brick Red for the single most important action on a screen — the Add to Cart button, the checkout button. Never use it for a heading, a background or a text colour. Its strength comes from being rare: one red element per screen, and the eye goes straight to it.

04 · Typography

Two typefaces

Karmic Skin uses two typefaces: Domine for headings, Montserrat for body text and interface. All text is Carbon Black — make text stand out with size and weight, not colour. Any text set in capitals is always Montserrat, never Domine.

Domine — headings
Skin is a relationship to be tended.
Ancient wisdom for modern people
A warm serif with presence at large sizes. Use it for display text and headings, always in sentence case — never in capitals. Weights: 400, 500, 600, 700.
Montserrat — body and interface

Montserrat is used for body text, labels, navigation and data. It is clean, even, and easy to read down to small sizes.

  • DisplayDomine · 46–80px
  • HeadlineDomine · 26–36px
  • Sub-headDomine · 18–21px
  • BodyMontserrat · 15–16px
  • Small / labelMontserrat · 11–13px
05 · Spacing & shape

Spacing, radius and layout

All spacing uses one scale, built on multiples of 4 pixels. Using the same set of gaps everywhere keeps layouts even and calm.

Spacing scale — multiples of 4 pixels
4  Smallest gaps
8  Inside a component
12  Label to value
16  Default gap between items
24  Padding inside a panel
32  Between blocks
48  Breathing room within a section
64  Top and bottom of a section
Corner radius
6 · pills, tags
12 · buttons, inputs
16 · cards, panels
100 · badges
Layout

Keep layouts generous

Hold content to a single column about 1080px wide, with wide margins. Leave plenty of empty space. A page should feel calm, never crowded.

Separate with space, not boxes

Group content with space and background colour, not borders. Only the things a user interacts with — inputs, buttons — carry a border.
