Method

How this dashboard is calculated

Sales rate per SKU = direct unit sales + bundle-component allocation (when a bundle is sold, each listed component's count goes up by the bundle's quantity). 90-day window is the primary forecast; 180-day shown alongside for trend comparison.

Days of cover = current Shopify on-hand ÷ daily rate (current stock only). Stockout date = when stock hits zero including incoming PO units, which land in the forecast on their ETA (see INCOMING_POS in the page source). If current stock would run dry before a shipment lands, a gap badge appears in the Incoming column. PO due = stockout date − 120 days lead time, i.e. the latest date to place the next PO. Status drives off PO due: Overdue if PO due is in the past · Urgent if within 30 days · Soon if within 60 days · OK otherwise. Amber marks the rows that need action now.

Bundles tracked (1 bundle sold = 1 unit each component): The Heroes Kit, Dew It Right, Age Confidence, Bright Future, Mama's Glow, Soft Intentions, The Hair Affair Bundle. Component map is in the page source — see BUNDLE_MAP if you need to correct it. Bundle SKUs are hidden from this list per directive (you only see the underlying components).

Why some rates differ between 90d and 180d: a stockout in the window will lower the rate for that period (Sleepytime Gelly hit zero in late March), and recently-launched products (Featherweight, Maui Waui, Tropic Thunder, Espresso Bar, The One & Only — all launched Sep 2025) won't have a meaningful 180d picture. The dashboard auto-uses the more conservative (faster) of the two when there's a strong divergence.

Packaging materials = the latest count of primary packs (jars / bottles) and secondary packs (cartons) held per SKU, stored in PACKAGING_STOCK in the page source (paste the next count there and update the date). Units fillable = the lower of the two (cartons only for bars, which have no primary pack). Cover = units fillable ÷ the same daily rate used in the forecast above, in months. Status: Low if packaging covers less than one lead time (120 days) of sales · Watch if under two lead times · OK otherwise. The count is used as reported; if a count was taken before an open PO was filled, subtract that PO's quantities first.

Monthly sales trend = units per calendar month (UK time), bundle-decomposed the same way as the rates, for the last 12 full months plus the current month to date. Lines use two inks and four stroke patterns, and each line is labelled at its right-hand end. Sales rates in the table still use the trailing 90 / 180 day windows.

Refresh cadence: inventory syncs from Shopify hourly via sync-shopify-inventory. Sales data updates with the next webhook + rebuild cycle (every 10 min). Click Refresh for an immediate Shopify pull (≈3 sec).
